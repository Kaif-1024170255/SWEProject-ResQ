# SWEProject - ResQ

ResQ is an operations tool connecting affected people, volunteers, NGOs, resource providers, and administrators around a shared, real-time dispatch view of emergency requests.

## Test Inventory & Verification

The project includes a mechanically verified test case inventory in [`docs/TEST_CASES.md`](docs/TEST_CASES.md) and [`docs/test-inventory.json`](docs/test-inventory.json).

To regenerate the inventory:
```bash
cd code/server
npm run inventory
```
