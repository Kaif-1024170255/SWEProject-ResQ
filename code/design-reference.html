RESQ / DESIGN REFERENCE / v1

Field Ops Ledger

A calm, legible operations console for coordinating emergency response — built to feel like a dispatch desk, not a startup landing page. Reference this file before styling any screen.

01 — Color

Ink#14213D
Paper#EEF0EE

Signal Amber#D98E2B
Response Teal#1F7A6C

Ink and Paper carry the interface. Slate is for secondary text and hairline borders. Amber, Teal, and Rust are reserved only for status meaning (pending, active/resolved, critical) — never used decoratively.

Public Sans carries all headings and reading text — a civic-infrastructure typeface, not a startup display face. IBM Plex Mono is used only for genuinely tabular or data-like content: request IDs, coordinates, timestamps, status codes.

03 — Status Chips

UNVERIFIED VERIFIED IN PROGRESS RESOLVED CRITICAL

Status is shown as a left-border tag with a monospace code — like a shipping manifest, not a pastel rounded pill. No drop shadows, no gradients.

04 — Buttons

Buttons state the action in plain active voice — "Claim this request," not "Submit." Minimal corner radius (3px). No arrow suffixes.

Rows, not cards. No shadows, no rounded thumbnails. Density and scanability matter more than visual flourish — this is read under pressure.

07 — Console Layout (map + rail)

Open Requests · Sector 4

The map is a primary surface, not an accessory widget — this is fundamentally a geography problem. Pin color always maps to the same status colors as the chips.

08 — Principles

Calm under load

No neon, no gradients, no urgency-by-decoration. Color is reserved for meaning, so it stays trustworthy when it matters.

Data is not decoration

Monospace, hairline borders, and left-border status tags exist because this is genuinely operational data, not because they look technical.

Plain, active language

"Claim this request," "Mark resolved," "No open requests here yet." No jargon, no filler, one job per label.

One board, five roles

Every role reads the same log and map with a different rail of actions — never five disconnected-looking apps.
